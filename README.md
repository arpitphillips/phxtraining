## 🎓 Internal Training Portal

A fully self-contained, single-file HTML web application for onboarding and training PHX INDIA employees.

**Open it:** Simply open `Internal Training/index.html` in any browser — no server or build step required.

### Features
- **Service Lifecycle Flowchart** — Interactive 12-stage workflow with clickable detail modals
- **Team Roles & Responsibilities** — CRM, Production, and Editing Studios with colour-coded ownership
- **Dos & Don'ts** — Operational guidelines organised by team
- **Policies & Rules** — Payment, communication, scope, and file handling policies
- **Knowledge Check Quiz** — 15-question assessment with pass/fail scoring (80% threshold)
- **Contact & Escalation** — Quick-reference with clickable phone numbers

### Tech
- Single HTML file (~99KB) — HTML + CSS + vanilla JavaScript
- No frameworks, no build step, no server required
- Responsive design (desktop + tablet + mobile)
- External CDN: Google Fonts (Inter) and Font Awesome icons
